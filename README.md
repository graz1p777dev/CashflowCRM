# Cashflow CRM

CRM клуба деловой игры CASHFLOW (Бишкек). Форк CRM Smilekit: то же ядро
(Next.js + Supabase), но без магазинных модулей и с разделом «Игры» —
расписанием, из которого Telegram-бот берёт даты и в которое возвращает
записи людей.

## Разделы

**Главное:** Дашборд · Игры · Сделки
**Аналитика:** Декомпозиция · Зарплата · Финансы · Маркетинг
**Управление:** Задачи · Сотрудники · Календарь · Уведомления · Документы
**Система:** Настройки · Помощь

Разделов «Заказы», amoCRM, WhatsApp и AI-лаборатории здесь нет: они были
завязаны на магазин Smilekit.

## Как связаны CRM, бот и люди

```
менеджер → «Игры» → публикует игру
                       ↓
        Telegram-бот показывает дату и свободные места
                       ↓
человек записывается → game_bookings + сделка в воронке → уведомление в CRM
                       ↓
    бот напоминает за сутки и в день игры, менеджер отмечает пришедших
```

Бот живёт отдельно: `~/Desktop/cashflow/bot` (Python, aiogram). Ходит в
CRM по HTTP через `/api/public/*` с общим секретом `BOT_API_TOKEN` —
ключей Supabase у него нет.

## Стек

- Next.js 16, React 19, TypeScript
- Tailwind CSS 4 + shadcn/ui
- Supabase (Postgres + Auth + Realtime)

## Запуск локально

```bash
cp .env.example .env.local   # заполнить ключи Supabase
npm install
npm run dev
```

## Миграции

`supabase/migrations` применяются по порядку на чистом проекте Supabase.
Игры, записи и переписка бота — `042_games.sql`, воронка записи —
`036_deals.sql`.

## Публичный API для бота

Все ручки требуют заголовок `x-bot-token: $BOT_API_TOKEN`.

| Метод | Путь | Зачем |
|---|---|---|
| GET | `/api/public/games` | опубликованные будущие игры со свободными местами |
| POST | `/api/public/bookings` | записать человека (идемпотентно по чату) |
| GET | `/api/public/bookings?chatId=` | брони этого человека |
| PATCH | `/api/public/bookings` | подтверждение или отмена своей брони |
| GET | `/api/public/reminders?withinHours=` | кому напомнить о ближайшей игре |
| POST | `/api/public/messages` | лог переписки для карточки сделки |
